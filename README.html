C# · xUnit · API Testing

csharp-api-tests

פרויקט תשתית לבדיקות אוטומטיות של REST API, בנוי ב-C# עם xUnit.

על הפרויקט

הפרויקט מדגים הקמה נכונה של סוויטת בדיקות אוטומטיות ל-API חיצוני (JSONPlaceholder), בפריימוורק הבדיקות הנפוץ בעולם ה-.NET — xUnit. הדגש הוא על מבנה נקי, שימוש נכון ב-HttpClient, וכתיבת טסטים קריאים וברורים שגם מתעד עצמם עם הערות הסבר, כך שכל מפתח או בודק שמגיע לקוד יכול להבין במהירות מה נבדק ולמה.

אסטרטגיית הבדיקות

כל בדיקה בפרויקט בנויה לפי שלושה שלבים ברורים (Arrange–Act–Assert):

  1. Arrange — הקמת HttpClient משותף עם כתובת בסיס, פעם אחת לכל המחלקה
  2. Act — שליחת קריאת HTTP א-סינכרונית (GetAsync) לנתיב הנבדק
  3. Assert — אימות שקוד הסטטוס שהתקבל תואם לציפייה (HttpStatusCode.OK)

דוגמה: GetPost_ReturnsOk

בדיקת "happy path" הבודקת שקריאת GET למשאב קיים (posts/1) מחזירה 200 OK.

[Fact]
public async Task GetPost_ReturnsOk()
{
    HttpResponseMessage response = await client.GetAsync("posts/1");
    Assert.Equal(HttpStatusCode.OK, response.StatusCode);
}

הרצת הבדיקות

מתיקיית השורש של הפרויקט:

dotnet test

הפקודה תאתר אוטומטית את כל המתודות המסומנות ב-[Fact] / [Theory] ותריץ אותן.
